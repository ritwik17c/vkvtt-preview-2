🧼 Sanitised Timetable Audit

This checker does not rewrite the Master Timetable. It resolves legacy teacher-code formats in memory and verifies how the operational engine should read them.

❌ Structural anomalies requiring attention

Only genuinely unresolved/contradictory structures appear here. A legacy entry such as Hindi-DK is no longer treated as an error when DK can be resolved from the assignment.

🔗 Combined teacher duties

Multiple class records for the same teacher, day and period are treated as one teacher duty / one proxy requirement. These are informational, not errors.

🗓 Active-schedule suppression

Master records that exist but are not active under the current schedule profile are listed here. This helps explain why an assignment may be visible in master data but absent operationally.
