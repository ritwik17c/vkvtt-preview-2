Admin Dashboard → Temporary Leave-Vacancy Replacements

👩‍🏫 Temporary Leave-Vacancy Replacements

The replacement teacher remains outside the permanent roster. During the selected dates, the app operationally places the temporary teacher in the absent teacher's timetable. The original master timetable is preserved.

Weekly pattern

Tick the absent teacher's periods that this teacher will take every week between the From and To dates. Every period can be customised. In the absent teacher's periods, tick the class shown to take it as usual, or tick Other class to choose any class and subject instead (the usual class will then need a proxy). In free periods, tick Extra and choose a class and subject. Whenever this teacher takes another teacher's class, that teacher becomes free for proxies.

Specific dates

Add a date to set its periods exactly, including any extra periods. A date listed here overrides the weekly pattern (and weekly extra periods) for that day.

Admin Dashboard → Class Period Blocks

⏸ Class Period Blocks

Use this when some classes will not have certain periods for a few days, for example when they are allowed to leave early. On the chosen dates, those periods are treated as not held: no proxy is needed, and the teachers of those periods are free for other proxies. The master timetable itself is not changed.
