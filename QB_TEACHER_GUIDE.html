Question Bank & Question Paper Builder

Create / Import → Review → Submit → Verify → Reuse → Build Paper → Check → Preserve
The Question Bank now supports quick individual submission as well as advanced Excel and Word bulk import. Every imported question is previewed before it is saved.

1. Who Can Use This Module?

  1. Linked teaching staff can use the Question Bank and Question Paper Builder.
  2. A teacher may also have delegated authority as a Subject Coordinator; that review area appears in addition to the normal teacher workspace.
  3. The Principal/Admin may also use the teacher workspace when linked to a teaching identity, and has a separate Principal / QB Admin area for oversight.
  4. Non-teaching staff do not receive the teacher Question Bank workspace.

2. Opening the Module

  1. Sign in to VKVTT using your authorised Google account.
  2. Open Question Bank & Paper Builder from your teaching area.
  3. The workspace contains Add Question, My History, Verified Bank, Paper Builder and Import / Export. Subject Coordinators also see the review area.

4. Voice Dictation

  1. Tap 🎙 Dictate Question.
  2. Select the required language where offered.
  3. Speak clearly. Recognised speech is added to the question field; it does not submit automatically.
  4. Stop dictation and review the transcription.
  5. Use basic correction helpers only as presentation aids; the teacher remains responsible for academic meaning.
Browser note: Speech recognition depends on the browser/device. If it is unavailable, type or paste normally.

5. Draft vs Submit

Save Draft keeps unfinished work in your own Question Bank history. Drafts are not sent for verification.

Submit to Subject Coordinator sends the question into the academic verification workflow. It remains visible in your History while awaiting review.

6. Status Meanings

Draft Teacher working record.

Awaiting Verification Submitted and waiting for Subject Coordinator review.

Returned for Correction Sent back with a correction note.

Verified / Approved Academically accepted and available in the verified Question Bank.

7. My Submission History

  1. Use the available filters to separate Verified, Awaiting Verification, Returned and Draft records.
  2. Use search to find a question by text, class, subject or visible metadata.
  3. Returned questions should be corrected after reading the coordinator's note.
  4. Bulk-imported questions also appear in My History; they are not kept in a separate hidden store.

8. Verified Question Bank

The shared Verified Bank contains coordinator-accepted questions. These can be reused while preparing teaching material or building papers.

Quality over repetition: Avoid repeated or near-duplicate submissions merely to increase counts. Accurate, reusable questions are more valuable to the school.

9. Subject Coordinator Review Inbox

  1. Review teacher, class, subject, question, marks, type and available metadata.
  2. Use ✓ Verify & Accept only after checking academic correctness, wording and appropriateness.
  3. Use ↩ Return where correction is needed and provide a useful note.
  4. The teacher sees the returned status and note in History.

If a Subject Coordinator submits questions in a subject for which that same person is the authorised coordinator, the current workflow may apply the configured coordinator self-verification route automatically. Teachers should still review all imported content carefully before submission.

11. Question Paper Builder

The Paper Builder provides a local-first workspace for assembling papers without altering the Question Bank merely by drafting.

  1. Create a paper and enter the target marks.
  2. Add and rename sections.
  3. Add section instructions where needed.
  4. Add questions and optional internal choices.
  5. Use the live marks indicators and paper-health checks.
  6. Review the final structure before printing or preserving a paper version.
Academic check remains essential: Automated counts, structure checks and health indicators assist the teacher; they do not replace final academic review.

12. Advanced Bulk Import — Excel & Word

The Import / Export area now supports a full Analyse → Preview → Correct → Save/Submit workflow. Uploading a file does not immediately write questions to the cloud.

Recommended workflow: Choose defaults → select Excel/Word file → Analyse & Preview → correct the preview → choose Save All as Drafts or Submit All for Verification.

A. Excel Import

  1. Open Import / Export and download the latest Excel Template.
  2. Use one question per row. The supported fields include Class, Section/Stream, Subject, Chapter/Unit, Topic/Sub-topic, Learning Outcome, Marks, Difficulty, Question Type, Question, Answer and Marking Scheme.
  3. The first worksheet is read by the importer.
  4. Choose useful common defaults in the screen before analysing. Spreadsheet values may override those defaults where supplied.
  5. Click Analyse & Preview. Nothing is saved at this stage.
Why use the downloadable template? It gives the safest headings and makes large imports much easier to validate. If you maintain your own spreadsheet, review the preview carefully before saving.

B. Word (.docx) Import

  1. Save the document as .docx. Old .doc files should first be opened in Word and saved as .docx.
  2. Number questions clearly, for example 1., 2., 3.. The importer uses the numbered structure to detect individual questions.
  3. Select common Class, Subject, Marks, Difficulty and Question Type before analysing.
  4. If a question itself ends with a marks note such as (2 marks), that question-specific marks value can override the common Marks setting.
  5. Click Analyse & Preview and review every detected question.
Word import is structured extraction, not magic conversion. If questions are not numbered consistently, or if a document contains complex tables/formatting, some questions may not be detected as intended. Always inspect the preview.

D. Analyse & Preview

After analysis, the questions appear in an editable table. You can correct important fields before saving.

  1. Check Class and Subject row by row.
  2. Check Marks and Question Type.
  3. Read the complete Question.
  4. Edit the Answer where needed.
  5. Rows with validation problems are highlighted and must be corrected before import.

The importer validates the batch before enabling the final save/submit actions.

E. Duplicate Protection

The advanced importer provides two layers of duplicate protection:

  1. Duplicates inside the uploaded file are detected and duplicate rows can be removed from the batch.
  2. Previously imported matching questions use a deterministic import fingerprint so that an already-existing imported question can be safely skipped rather than silently duplicated.
The preview shows the question count and the number of duplicate rows removed. Duplicate protection is a safety aid; teachers should still avoid submitting cosmetically altered versions of the same question.

F. Save as Drafts or Submit Directly

After the preview is valid, choose one of the two final actions:

Save All as Drafts
Keeps the imported questions in your History as working records. They do not enter coordinator review yet.
Submit All for Verification
Sends the imported questions into the normal Subject Coordinator workflow.

A confirmation is shown before the batch is saved. During saving, progress is displayed. When complete, imported questions are available in My History.

G. Import Limits & Safety

  1. Supported teacher bulk-import formats are .xlsx, .xls and .docx.
  2. The current teacher import accepts files up to approximately 12 MB.
  3. The importer processes a maximum of approximately 500 question rows per batch; very large banks should be split into manageable files.
  4. Always keep a copy of the original Excel/Word source until the import has been checked in My History.
  5. Never assume that successful parsing means academic correctness. Preview and proofread before final submission.

H. If an Import Stops

  1. Do not repeatedly press Submit without checking the message.
  2. If the file was analysed successfully, the source file itself may be fine; note the exact error message.
  3. Refresh the page after any administrator-side permission correction and analyse the file again.
  4. The deterministic duplicate protection is designed to avoid duplicating questions that were already successfully saved before an interrupted batch.

13. Export

Use Export My Questions to download your own Question Bank records. Principal/Admin reporting and analytics are handled separately.

14. Good Question-Bank Practice

  1. Write questions that are clear, answerable and appropriate for the class level.
  2. Choose marks that match the expected depth of response.
  3. Use difficulty thoughtfully.
  4. Add Learning Outcome / Competency information when it genuinely helps future reuse.
  5. Include a useful answer or marking scheme where evaluation may otherwise be ambiguous.
  6. Avoid duplicates and cosmetic variations of the same question.
  7. For bulk imports, review the preview instead of treating the spreadsheet or Word file as automatically correct.
  8. The submitting teacher remains responsible for the final academic quality of every question.
Remember: The Question Bank is not merely a counting system. Every good verified question becomes a reusable academic resource for future papers, revision, practice and school-level planning.
