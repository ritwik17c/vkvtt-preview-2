# Leave Master Editor v62 — Quick Guide

## Continuous leave
Use **Date entry tools** → From Date → To Date → Status → Leave Category → **Generate Date Rows**.
The app creates one row for every calendar date in the chosen range. Review the rows and remove dates that are not actually part of the approved leave before saving.

## Scattered dates / mixed categories
Use **Add date row** and enter each actual date separately. Different rows may have different categories/statuses.

## Period fields
**From Period / To Period** are relevant only to half-day, OD or Special Assignment period ranges. They are hidden for Full Leave.

## Duplicate/conflict protection
Run **Leave Integrity Checker** at any time. The editor also checks before saving:
- exact duplicate → save blocked
- overlapping contradictory approved status → save blocked

Edit or archive the existing record instead of creating a contradictory second record.

## Legacy pending items
Do not invent dates. Use verified leave application/sanction, attendance/proxy records or another approved school source. The entered leave units must reconcile with the parked legacy amount.
