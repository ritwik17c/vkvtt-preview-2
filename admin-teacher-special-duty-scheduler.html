🎯 Teacher's Special Duty Scheduler

Assign recurring special duties without rewriting the Master Timetable. Duties covering selected teaching periods become an operational unavailability overlay for Proxy Allotment.

Special Duty Rows

Tick one or more days. Enter From/To time for the duty. Select From Period and To Period whenever the duty overlaps class time; those periods will automatically be treated as unavailable in the Proxy module.
